# Automated Data Cleaning and Reporting System

A college-ready Python project that automates data cleaning and reporting.

## Features
- CSV input
- Missing-value handling
- Duplicate removal
- Inconsistent text standardization
- Numeric validation
- Automated grade calculation
- Summary CSV files
- PNG visualizations
- HTML report

## Run
```bash
pip install -r requirements.txt
python automated_cleaning_reporting.py
```

Open `output/automated_report.html` in a browser.
